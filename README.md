# 🎧 AI Music Web App

A modern, powerful, and completely free web-based music player with **AI-powered recommendations**, **video-to-audio playback**, and a seamless listening experience.

---

## 🚀 Features

✨ **AI Music Suggestions**  
Get smart recommendations based on what you're currently playing.

🎵 **Play Video as Audio**  
Stream videos as pure audio (perfect for saving data & background listening).

📀 **Smart Music Queue**  
Automatically queues songs from the same artist or similar vibe.

🔁 **Auto Next Play**  
Never stop listening — continuous playback enabled.

🧠 **Context-Aware Recommendations**  
AI suggests tracks based on:
- Artist
- Genre
- Listening pattern

📱 **Fully Responsive UI**  
Works smoothly on:
- Mobile 📱  
- Tablet 💻  
- Desktop 🖥️  

⚡ **Fast & Lightweight**  
Optimized for speed with smooth playback.

🆓 **100% Free**  
No subscriptions. No hidden fees. No premium lock.

---

## 🧩 Core Functionalities

- ▶️ Play / Pause / Skip
- 🔊 Volume control
- 📃 Dynamic playlist rendering
- 🔍 Search music
- 🧠 AI suggestion engine
- 🎬 Extract audio from video sources
- 🎶 Artist-based queue system

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **AI Engine:** Custom logic / API-based recommendations
- **Media Handling:** HTML5 Audio / Video APIs
